Jade File Encryption

Lock and unlock files with your Jade. Experimental: use test files only.

Experimental. Do not use for real files. This tool has not been audited or reviewed. Use it only with files you can afford to lose or expose. If you want to try it seriously, first restore your wallet on a second Jade and check that a test file decrypts.

What this page does
  • Sends Jade four commands: version info, unlock, fetch the file public key, and one ECDH call per decryption. Jade returns a public key and a per-file shared secret. The private key is not part of the protocol and is never sent to the page.
  • Unlocking Jade with your PIN is the only approval. In current firmware the decrypt call shows no confirmation screen on Jade. While Jade is unlocked and plugged in, other software on this computer could use it the same way. Disconnect when you are done.
  • Relays Jade's PIN handshake to Blockstream's pinserver during unlock. That is the only network request in this page's code; you can confirm it in your browser's network tab. Files and their decrypted contents are handled in this tab.
  • Writes standard OpenPGP files. GnuPG recognises them, and GnuPG with jade-agent should be able to open them without this page. That recovery path has not yet been tested on hardware.
  • Derives the key from your wallet seed and its BIP39 passphrase, if you use one. A wallet restored without the passphrase gets a different key and cannot open your files.
  • Needs Web Serial, which Chrome, Edge and Brave provide on desktop. Safari and Firefox do not.
